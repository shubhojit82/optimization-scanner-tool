Setup & client management
＋
Add Client
The unit of all analysis — one client = one brand + domain
Implemented

Create a client by supplying brand name, domain, industry, target market, up to 10 products/services, and up to 5 competitor brands. All scoring, probing, and observation tracking is scoped to a single authenticated owner — no data crosses clients.

  • 1Add client — top-right button, fill in the form
  • 2Edit client / Brand identity — update name, add brand aliases (e.g. "WFG") so mention matching covers all known names
  • 3Import page — paste page HTML to establish the first readiness baseline
  • 4Delete client — two-click confirmation, permanently removes all audits, observations, and probe runs
Page analysis
📊
Overview — Client Readiness
Composite SEO / AEO / GEO score with per-dimension breakdown and priority actions
Implemented

The main view. Shows the weighted readiness score (0–100) across all assessed dimensions, the rubric coverage %, and three sub-scores. Click any sub-score ring (SEO / AEO / GEO) to drill into a full page-by-page breakdown with findings and how-to-fix guidance.

Priority actions — dimensions ordered by weighted gap (weight × (100 − score)), so the highest-impact missing cues always appear first. Each action includes traceable evidence from the HTML.

Evidence ledger — full history of audits. Click any row for the dimension detail. Export as HTML report, PDF (print dialog), or JSON.

Note: Score = sum(weight × score) ÷ assessed weight. Dimensions with null scores are excluded from the average but reduce rubric coverage. High scores do not guarantee ranking or AI visibility.
🔍
Scanner
Scan any public URL without pasting HTML — live HTTP fetch + instant GEO readiness report
Implemented

Enter any public URL; the server fetches it with a Node HTTP crawler (or headless browser if GEO_USE_BROWSER=true). Returns the full dimension breakdown, SEO/AEO/GEO sub-scores, and flagged findings immediately. Results are cached for 5 minutes to avoid duplicate fetches.

  • 1Paste URL → Scan
  • 2Review findings → Save to client to persist the audit (deduplicates by hash+url)
  • 3Export XLSX — full GEO readiness report in spreadsheet format
🗺️
Site Crawler
Discover and score multiple pages from a single domain automatically
Implemented

Enter a root URL and the crawler discovers pages via sitemap.xml or internal link traversal. Each page is scored against the full GEO rubric. Returns a ranked list with per-page SEO/AEO/GEO sub-scores and top gaps, plus an XLSX export of the full site report.

📈
Progress
Before-and-after dimension comparison across any two saved audits
Implemented

Select any two audits from the client history. Shows delta per dimension — green for improvements, red for regressions. Answers the question: "Did the fix actually land?"

AI visibility & probing
⚡
AI Visibility
Fire prompts at live AI engines — measure brand mention rate, sentiment, share-of-voice
Implemented

Runs a set of prompts against one or more configured AI providers (OpenAI, Gemini, Claude, Perplexity). For each response it measures: brand mentioned (yes/no), sentiment (positive / neutral / negative / absent), whether the client domain was cited, and which competitors appeared.

Aggregates into: Mention Rate, Citation Rate, Sentiment Breakdown, Share of Voice vs each competitor, and Top Citing Domains.

Requires: At least one API key in .env — OPENAI_API_KEY, GEMINI_API_KEY, ANTHROPIC_API_KEY, or PERPLEXITY_API_KEY.
👁️
AI Monitor
Run a single prompt against a specific provider and save the observation instantly
Implemented

Lighter-weight than a full probe run. Select provider, pick or type a prompt, get the response with citations in real time, and save it to the client's observation history. Good for spot-checking a specific query without burning credits on all providers.

🔔
Schedules
Automated recurring probe runs — daily, weekly, or monthly
Implemented

Set a cadence (daily / weekly / monthly), choose providers and prompts, and the server's built-in scheduler fires probes automatically in the background. No external cron needed — the scheduler polls on server start.

🚨
Alerts
Threshold-based alerts on mention rate, citation rate, or overall score
Implemented

Define a metric (mention rate / citation rate / score), a direction (below / above), and a threshold (0–100). After each probe run the server checks all enabled alerts and timestamps those that triggered. Review which alerts fired and when in this panel.

Competitive intelligence
📉
Competitors
Scan up to 5 competitor URLs and compare SEO / AEO / GEO scores side-by-side
Implemented

Enter competitor URLs; the scanner fetches each page and scores it against the same GEO rubric used for the client. Returns a ranked table with overall score, coverage, SEO/AEO/GEO sub-scores, and the top 3 dimension gaps per competitor. Competitor scans share the 5-minute in-process cache.

🏆
Benchmark
League-table scoring of 2–6 URLs with gap analysis vs the leader
Implemented

Score any mix of URLs (client pages + competitors) in a single ranked table. Highlights the leader per sub-score and shows each entry's gap vs the top performer. Useful for client presentations showing relative positioning.

AI-powered content & strategy
🪄
Smart Prompts
AI-generated probe prompts tailored to your audit gaps and personas
Implemented

Requires a prior page audit. Sends audit gap data to the selected AI provider, which returns intent-matched, persona-targeted probe questions designed to test brand visibility in the specific areas where the client scores lowest. Better than generic query-universe prompts for targeted measurement.

✏️
Content Brief
AI-generated content brief from audit gaps — headings, FAQs, schema markup, entity links
Implemented

Requires a prior audit. The selected AI provider analyses the dimension gaps and outputs a structured content brief: specific H2/H3 headings to add, FAQ questions to answer, schema types and properties to implement, entity link targets (Wikidata, Wikipedia, LinkedIn), and passage blocks. Ready to hand to a content writer.

Reporting & export
🎯
Action Plan
Prioritised fix list ordered by effort vs impact — start with quick wins
Implemented

Pulls dimension gaps from the latest audit and ranks them by weighted impact. Groups fixes into SEO, AEO, and GEO tracks. Each action includes what to change, why it matters, and the expected score impact. Designed to be copied directly into a project brief or sprint backlog.

📋
Executive Summary
Client-ready PDF report — 5-pillar scores, AI visibility KPIs, top recommendations
Implemented

Generates a polished, printable HTML report containing: IBM 5-pillar readiness scores, AI visibility metrics from the latest probe run, top 5 recommendations with projected uplift, and a competitor comparison if scans exist. Download and print to PDF from the browser.

📑
Full HTML Report / XLSX Export
Lighthouse-style audit report and spreadsheet export from the Evidence Ledger
Implemented

HTML Report — from the Overview evidence ledger. Lighthouse-style report with all dimensions, findings, evidence, and how-to-fix for every assessed cue. Share with developers or include in a delivery pack.

XLSX Export — available from Scanner. Spreadsheet with SEO/AEO/GEO sub-scores, per-dimension findings, and top gaps. Suitable for client presentations.

Query universe & observations
🔎
Query Universe
Auto-generated prompt set by intent — Education, Evaluation, Implementation, Comparison
Implemented

Deterministically generates a repeatable set of prompts from the client's products, market, and competitors — no LLM call needed. Each prompt has an intent label. Run any prompt directly from this tab into the AI Monitor, or export all prompts as JSON. Add and save custom prompts to supplement the auto-generated set.

🌐
Observations
View, import, and manage saved AI engine responses with citation tracking
Implemented

The observation ledger shows all saved AI responses with mention rate and citation rate. Supports three import paths:

  • ALive AI Monitor — run a prompt against a provider and save in one click
  • BJSON import — paste a JSON array of observations (useful for Postman/API-collected data)
  • CCSV import wizard — bulk-import from a spreadsheet with column mapping

Rates are computed over the latest 200 observations per client.

Workspace & integrations

Dashboard
Multi-client overview — all clients ranked by score at a glance
Implemented

Shows all saved clients with their latest audit score and sub-scores in a summary table. Click any client to jump straight to their Overview. Useful when managing multiple accounts.
